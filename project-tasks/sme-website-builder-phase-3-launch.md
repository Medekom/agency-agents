# Phase 3 — Développement du site + génération de contenu

## Statut
Phase 3 prête au lancement : architecture Phase 2 validée, implémentation peut commencer.

## Objectif
Développer le système de génération de sites et le workflow de prospection pour SME Website Builder.

## Instructions pour l'Agents Orchestrator

1. Lire la task list : `project-tasks/sme-website-builder-tasklist.md`
2. Confirmer que Phase 2 est complète (documents validés)
3. Activer les agents suivants :
   - `Frontend Developer` (implémentation génération site)
   - `Backend Developer` (moteur génération contenu)
   - `Email Intelligence Engineer` (préparation outbound commercial)
   - `Evidence Collector` (QA progressive et validation)
4. Produire les livrables suivants :
   - composant de sélection et qualification PME
   - système de génération automatique des pages (accueil, services, à propos, contact)
   - génération de contenu texte réel personnalisé par secteur
   - application du design responsive mobile-first
   - génération de visuels/maquettes (screenshots desktop/mobile)
   - préparation de l'email commercial avec screenshots intégrés

## Deliverables attendus
- Code fonctionnel du générateur de sites (Eleventy + templates)
- Templates de pages optimisés selon direction marque Phase 2
- Moteur de génération de contenu avec données PME réelles
- Système de capture de screenshots automatisée
- Template d'email commercial complet avec pièces jointes

## Qualité
- Validation progressive par `Evidence Collector`
- Tests de génération sur cas PME réels
- Performance des sites générés (Core Web Vitals < 2s)
- Qualité du contenu crédible et sectoriel
- Respect de l'architecture UX et direction marque Phase 2

## Métriques de succès Phase 3
- Sites générés en < 30 secondes
- Contenu 100% crédible et personnalisé
- Screenshots desktop/mobile parfaits
- Email commercial prêt à l'envoi
- QA validation complète avant Phase 4
