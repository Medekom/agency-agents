# SME Website Builder — Task List

## Phase 1 — Analyse du besoin et définition des tâches

### 1.1 Définir le périmètre de prospection
- [ ] Définir les critères de qualification des PME françaises
  - chiffre d'affaires cible (> 500k€ ou paramétrable)
  - secteurs prioritaires (B2B, services locaux)
  - localisation et taille d'entreprise
- [ ] Spécifier les éléments qui caractérisent un site obsolète
  - non responsive
  - contenu obsolète
  - design ancien
  - page introuvable / site absent

### 1.2 Définir les données prospect à collecter
- [ ] Nom de l'entreprise
- [ ] Secteur d'activité
- [ ] Localisation
- [ ] Chiffre d'affaires estimé ou seuil
- [ ] Statut web actuel (absent / obsolète / faible présence)
- [ ] URL existante le cas échéant
- [ ] Description de l'activité

### 1.3 Définir l'offre produit
- [ ] Spécifier les pages du site à générer
  - page d'accueil
  - page services / prestations
  - page « À propos »
  - page contact
- [ ] Spécifier les besoins de contenu réel
  - texte entreprise personnalisé
  - proposition de valeur claire
  - éléments de confiance (témoignages, éléments métiers)
- [ ] Spécifier le format des visuels
  - maquettes ou images libres de droits
  - captures d'écran desktop et mobile

### 1.4 Définir le workflow commercial
- [ ] Décrire le flux d'email de prospection
  - objet de l'email
  - valeur proposée
  - proposition d'abonnement
  - CTA clair
- [ ] Définir les livrables du mail
  - texte commercial
  - screenshots du site généré
  - lien vers démonstration ou résumé du projet

### 1.5 Définir les critères de validation QA
- [ ] Définir les critères d'acceptation pour le prospect
  - pertinence de la cible
  - qualité du statut web identifié
- [ ] Définir les critères d'acceptation pour le site généré
  - responsive mobile et desktop
  - contenu adapté et crédible
  - design moderne et professionnel
- [ ] Définir les critères d'acceptation pour l'email
  - clarté de l'offre
  - présence d'une proposition d'abonnement
  - inclusion des captures d'écran

### 1.6 Planification de la pipeline
- [ ] Confirmer le plan de mise en œuvre en 5 phases
- [ ] Assigner les agents nécessaires
  - `project-manager-senior`
  - `UX Architect`
  - `Brand Guardian`
  - `Frontend Developer`
  - `Backend Architect`
  - `Evidence Collector`
  - `Reality Checker`
- [ ] Documenter les entregables par phase
