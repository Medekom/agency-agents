# SME Website Builder — Architecture UX / Produit

## Objectif
Fournir une base UX solide pour la génération de sites web modernes destinés aux PME françaises sans site ou avec un site obsolète.

## Principes UX
- Mobile-first : prioriser l’expérience sur smartphone tout en assurant un rendu desktop performant.
- Clarté de la proposition : chaque page doit expliquer rapidement ce que fait l’entreprise et pourquoi c’est pertinent.
- Confiance : intégration d’éléments de preuve sociale, de crédibilité et de contact clair.
- Simplicité : structure de pages concise, navigation facile et contenu minimal mais riche.

## Personas clés
- **Dirigeant de PME**
  - Objectif : obtenir rapidement une présence web professionnelle sans effort.
  - Besoins : visibilité locale, crédibilité, conversion simple.
- **Responsable commercial**
  - Objectif : présenter les services de l’entreprise de manière claire.
  - Besoins : messages orientés bénéfices, contacts faciles à trouver.

## Architecture de l’information
### Pages principales
1. Page d’accueil
   - accroche forte + proposition de valeur
   - résumé des services clés
   - preuves sociales / avantages
   - appel à l’action vers contact ou démonstration
2. Page Services / Prestations
   - présentation 3-4 offres principales
   - bénéfices concrets pour le client
   - visuels métiers simples
3. Page À propos
   - histoire de l’entreprise
   - mission et valeurs
   - expertise sectorielle
   - témoignage client ou chiffre clé
4. Page Contact
   - formulaire de contact simple
   - coordonnées
   - zone de service / localisation

### Sections secondaires
- FAQ courte (optionnelle)
- Témoignages ou illustrations de projets
- Bandeau de conversion persistante en bas de page

## Parcours utilisateur
1. Arrivée sur la page d’accueil
2. Compréhension rapide de la valeur
3. Exploration des services
4. Validation de la crédibilité
5. Passage à l’action via le contact

## Principes de contenu
- Utiliser un langage professionnel mais accessible.
- Éviter le jargon inutile.
- Donner des exemples concrets reliés au secteur de l’entreprise.
- Prioriser les bénéfices clients sur les caractéristiques.

## Wireframes fonctionnels
### Page d’accueil
- header : logo, navigation, CTA principal
- hero : titre, sous-titre, image/illustration métier
- offres clés : 3 blocs de services
- preuve : témoignage ou chiffre clé
- footer : contact rapide, mentions légales

### Page Services
- titre explicite
- cartes de service avec description courte
- appel à l’action sur chaque service

### Page À propos
- accroche de confiance
- sections : mission, équipe / expertise, histoire
- citation ou point de crédibilité

### Page Contact
- formulaire court (nom, email, message)
- coordonnées claires
- carte ou zone de service

## UX technique
- Utiliser des composants réutilisables : cards, CTA, section feature.
- Prioriser le temps de chargement : images optimisées, CSS chargé rapidement.
- Respecter l’accessibilité : contraste élevé, structure sémantique, navigation clavier.

## Éléments de validation UX
- Navigation intuitive entre les sections
- Call-to-action visibles et cohérents
- Contenu structuré par priorité d’information
- Expérience mobile fluide avec boutons tactiles larges
