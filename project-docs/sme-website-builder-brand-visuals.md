# SME Website Builder — Direction visuelle et baseline de marque

## Objectif
Définir une direction visuelle moderne et professionnelle adaptée aux PME françaises ciblées.

## Positionnement de marque
- Proposition : "Un site web professionnel livré rapidement, pensé pour les PME qui veulent retrouver une présence digitale cohérente sans complexité."
- Ton : clair, confiant, utile.
- Valeurs : fiabilité, proximité, efficacité.

## Palette de couleurs
- Primaire : Bleu profond (#1D4ED8) — crédibilité et sérieux
- Secondaire : Vert doux (#10B981) — croissance et confiance
- Accent : Jaune lumineux (#F59E0B) — action et mise en avant
- Neutres : Gris foncé (#111827), Gris clair (#F3F4F6), Blanc pur (#FFFFFF)

## Typographie
- Titres : Inter Bold / Lexend Deca Bold
- Texte courant : Inter Regular / Noto Sans Regular
- Accents : Inter SemiBold pour CTA et titres de section

## Style des composants
### Boutons
- CTA principal : fond bleu profond, texte blanc
- Bouton secondaire : contour bleu profond, texte bleu profond
- Bouton d’action secondaire : fond vert doux, texte blanc

### Cartes services
- fond blanc, ombre légère, bord arrondi
- titre large + description courte
- icône simple ou petit visuel métier

### Sections visuelles
- Hero : image métier ou illustration stylisée
- Sections de preuves : chiffres clés, témoignages
- Footer : fond gris clair, liens clairs

## Images et visuels
- Style naturel : photos d’équipes, de bureaux locaux, de services en action.
- Option : illustrations simples liées aux métiers (boulangerie, plomberie, artisans, services B2B).
- Toujours privilégier l’authenticité et l’aspect professionnel.

## Voice & copy guidance
- Message principal : "Votre nouvelle vitrine web, prête à vous faire gagner plus de clients."
- Approche bénéfice : "Augmentez votre visibilité locale", "Transformez les visiteurs en contacts".
- CTA : "Demandez votre site sur-mesure", "Recevez votre proposition".

## Brand elements
- Logo : simple, typographie nette, signe évoquant une vitrine ou un écran.
- Forme : angles arrondis pour rassurer, lignes horizontales pour la stabilité.
- Icônes : minimalistes, filaires, avec accent de couleur.

## Règles d’utilisation
- Conserver l’espace autour du logo.
- Ne pas mélanger plus de 3 couleurs d’accent sur une page.
- Garder le contenu centré et aéré.
- Assurer un contraste de 4.5:1 pour tous les textes principaux.
