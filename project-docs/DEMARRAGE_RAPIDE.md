## 📞 QUESTIONS FRÉQUENTES

**Q: Peut-on réduire la durée?**  
R: Non facilement. Les dépendances entre phases sont réelles. Paralléliser c'est +risque.

**Q: Peut-on réduire l'équipe?**  
R: De 13-14 à maximum 10 FTE, mais alors timeline passe à 20-24 semaines.

**Q: Peut-on réduire le budget?**  
R: Dificilement. €1M c'est 650K en salaires. Infrastructure ~100K. Difficile de faire moins sans sacrifier qualité.

**Q: Quel est le ROI?**  
R: €12.5K/week = €650K/an. Donc ROI positif en ~10 mois. Voir RESUME pour calcul détaillé.

**Q: C'est vraiment prêt à implémenter?**  
R: Oui. Tous les specs, APIs, data models sont détaillés. Les équipes peuvent commencer immédiatement Week 1.

**Q: Qui gère quoi?**
R: [INDEX_NAVIGATION.md](INDEX_NAVIGATION.md) a une section "Documents par Rôle".

**Q: Où est le code?**
R: C'est un plan. Le code sera créé par vos équipes dev Weeks 1-16 en suivant les specs.
