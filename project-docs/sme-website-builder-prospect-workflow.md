# SME Website Builder — Workflow d'analyse et de génération de prospects

## Objectif
Décrire le workflow opérationnel pour identifier les PME cibles et générer le site web et le package commercial.

## Étape 1 : Prospection ciblée
- Définir les sources de données : annuaires entreprises, PagesJaunes, OpenStreetMap, data B2B.
- Filtrer les PME françaises par secteur, localisation et taille.
- Identifier celles qui ont un bon potentiel commercial.

## Étape 2 : Diagnostic web
- Vérifier l'URL publique de l’entreprise.
- Catégoriser le statut web :
  - absent
  - obsolète (design ancien, non responsive, contenu obsolète)
  - faible présence (page unique, contact limité)
- Collecter des informations clés : titre de la page, méta description, présence d’un formulaire, mobile friendly.

## Étape 3 : Qualification
- Attribuer un score de priorité basé sur :
  - absence de site (+ haute priorité)
  - site non responsive
  - absence de contenu de présentation
  - chiffre d'affaires estimé élevé
- Sélectionner la liste finale de prospects à traiter.

## Étape 4 : Génération de la fiche entreprise
- Rassembler : nom, secteur, localisation, présentation, points forts, services clés.
- Générer un texte personnalisé pour :
  - page d’accueil
  - page services
  - page À propos
  - page contact

## Étape 5 : Génération du site
- Appliquer le template UX / design
- Créer les pages suivantes :
  - accueil
  - services
  - à propos
  - contact
- Générer les visuels ou placeholders métiers.

## Étape 6 : Raffinement et validation
- Vérifier le rendu mobile et desktop.
- Vérifier la cohérence des contenus.
- Corriger les titres, CTA et descriptions si nécessaire.

## Étape 7 : Packaging commercial
- Prendre des screenshots du site généré.
- Créer un email d’approche contenant :
  - accroche personnalisée
  - bénéfices du nouveau site
  - preuve de valeur
  - offre d’abonnement claire
  - lien vers la démo ou pièces jointes

## Étape 8 : Préparation du suivi
- Prévoir un plan de relance après l’envoi du premier email.
- Définir les métriques de succès : taux d’ouverture, taux de clic, réponse positive.

## Règles de qualité
- Prioriser la crédibilité du contenu plutôt que la quantité.
- Conserver une structure simple et logique.
- Vérifier que chaque prospect peut comprendre l’offre en moins de 10 secondes.
